# homebrew-tap

Homebrew formulae for my projects.

## pre

Portable slide + audio container format — package single-page HTML slides and narration audio into one `.pre` file, playable in any browser.

    brew install Z-Mackintosh/tap/pre

The formula is updated automatically by [goreleaser](https://goreleaser.com) on every release of [Z-Mackintosh/pre](https://github.com/Z-Mackintosh/pre).
