# homebrew-tap

Homebrew casks for my projects.

## pre

Portable slide + audio container format — package single-page HTML slides and narration audio into one `.pre` file, playable in any browser.

    brew install --cask Z-Mackintosh/tap/pre

The cask is updated automatically by [goreleaser](https://goreleaser.com) on every release of [Z-Mackintosh/pre](https://github.com/Z-Mackintosh/pre).
